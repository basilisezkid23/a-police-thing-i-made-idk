# Installation

Go to the releases to get the .zip OR clone the repistory with:

```bash
$ git clone https://github.com/basilisezkid23/a-police-thing-i-made-idk
```

Then install the pygame library: (Recommended to use Python 3.12, Well that worked for me idk)

```bash
$ pip3 install pygame 
```
